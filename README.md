# Megical-Pen

How to use it:
1. Allow camera access.
2. Hold SHIFT key to start drawing.
3. Place your hand in front of the camera after granting access.
4. Choose colors from the top options to change drawing color.
5. Press Spacebar to erase everything and start fresh.

LIVE DEMO 
link : https://megical-pen.vercel.app

Note:
You can draw only as long as you keep the Shift key pressed. As soon as you release the Shift key, you won’t be able to draw anymore.
